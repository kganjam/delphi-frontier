The project's three preregistered endpoints

Model: a solid 8×4×3 block of 10 mm soft voxels (E 1 MPa) on a frictional floor. Every voxel contracts, and the patterns differ only in phase. Displacement is measured after a 1 s transient. Thresholds were committed before any data existed.

What this does not show

  • It is not tissue. No material value is measured, and contraction is a thermal proxy, which is the project's own modelling choice; the sources report ciliary locomotion.
  • There is no fluid, so motion comes only from ground contact. None of the construct's four missing couplings is closed.
  • There is no convergence claim. The fine mesh changes the wave by 14% and the short-axis wave by 4.3×.
  • It is not a reproduction of Kriegman 2020 or Blackiston 2021. The voxcraft-sim LICENSE file says CC0, while the cdorgs website says CC BY-NC; both are recorded.
  • Throughput: the unmodified engine manages about 17k simulation-steps/s on L40S, and 1000 bodies at E 1 MPa did not finish in an hour.
