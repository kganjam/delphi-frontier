2. **Reuse check against the existing Price proofs.** I read both files. `DelphiPrice` (`b4e60db9:experiments/price_probe/Price.lean`) is frequency-weighted and real-valued, and its `price`/`selection_only` need only `mean p w ≠ 0`. Δ_NS is exactly `descendantMean p w g − mean p g`. So T1 = `selection_only p w g` plus the new projection step `cov p w g = cov p g g`, built from `cov_add`, `cov_scale` and `cov_const`. `fitness_selection` (z = w) is a different statement. `lean_price/Price.lean` (`PriceProbe`) uses unweighted individual means, so it is not the right base (spec §7).
