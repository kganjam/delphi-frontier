## Structure predictions on the Nebius Scientific AI MCP (`structures/`)
PDB70 MMseqs2 MSAs (`msa_search_native`; 14-122 sequences, structural database only). Boltz-2 (`boltz2_predict_native`, 3 diffusion samples, no seed accepted by the runtime). Per-model numbers are in `structures/summary.json`.

- **ShhN** (Shha 24-197, mature signalling domain): mean pLDDT **85.1** and pTM 0.82. OpenFold2 with a dummy MSA scored 40.2 on the same residues. This is the first confident fin-pathway structure here, and it was used as the MD start.
- **Fgf10a core (58-201) + Fgfr2 IIIb D2-D3 (F1RBT3 150-360)**: chain pLDDT 86.7/85.1, interface pLDDT 71.7, confidence 0.77 (top of 3). 18 of 38 receptor interface residues fall in the IIIb/IIIc alternative-exon segment (F1RBT3 314-358), which is 21 % of the construct. That fits the known exon-dependent FGF10-FGFR2b specificity, but the PDB70 MSA contains the human complex's chains, so templating is likely (argon). The discriminating test is the IIIc negative control below.
- Kcnk5b dimer: Boltz-2 failed (`NATIVE_UPSTREAM_FAILED: All proteins with the same sequence must share the same MSA`) even though both chains carried identical A3M text. The receipt is in `structures/kcnk5b_dimer_boltz2_failed/`. Retried with OpenFold3.

## Blocked
The manifest-based MCP tools (`submit_openmm_workflow`, `submit_alphafold3`, `submit_bioemu2`, `submit_stab_ddg`) need an "artifact manifest" whose format is not published. My guess was rejected with `INVALID_REQUEST: invalid scientific artifact manifest` (`md_shhN/hosted_openmm_mcp_attempt_receipt.json`), and the gpuops harness's earlier ESMFold2 attempt was rejected the same way. So no AlphaFold3, BioEmu2 or stab_ddg run exists. MD went to a raw Nebius H100 job instead.
