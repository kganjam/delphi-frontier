# Scoped regional design assurance

Run `python -m engineering.assurance.build --output artifacts/assurance` from the
repo root. The stdlib-only projector reads integrated artifacts, recomputes source
SHA256 identities and emits `map.json` plus its manifest. It does not rerun Lean
or simulations, query a service, or alter Evidence declarations/reviews.

The assurance vector separates formal properties, numerical fidelity, empirical
validation, parameter coverage, cross-scale transfer and ensemble robustness.
No global biological-success probability or composite trust score is produced.
Blue numerical checks and grey biological accuracy can coexist: a differential
equation solver can be accurate while the target fish remains uncalibrated.

Region names are UI annotations, not measured anatomical segmentation. Regional
membership does not establish that an equation describes that biological part.
Scale anchors match the existing `flying-fish:<scale>` studio anchors. Every
conclusion is tied to a hashed artifact and bounded selector; exact snapshot refs
are retained separately from live-store scientific acceptance.

The interface matrix is inspired by an interaction-error display, but contains
categorical typed/scenario/refused/unknown transfers. No numerical spatial error
or zero diagonal uncertainty is invented. Electrical current dimensions are
preserved; voltage-to-fin stiffness is explicitly refused. Existing couplings
retain their individual port relations, assumptions and missing calibrations.

Shared sources, aerodynamic assumptions, model structure and paired seeds remain
dependence groups. Replicate runs, copied artifacts or movie frames are not
independent biological confirmations. The default artifact does not reinterpret
exploratory sweeps as prospectively declared robustness experiments.

The equation registry pins actual source implementations/Lean definitions,
variables/units/roles, applicability assumptions, numerical/formal checks, ports
and coupling IDs. Missing developmental and gene-to-fin laws are gaps with no
equation. A region exposes its applicable scoped equations and unsupported input
chain; the list is not a connected whole-organism developmental model.

Known findings retained in the initial projection:

- Formal, HH and fin-beam recorded source hashes match current bytes.
- The mechanobio model/control code matches, while the old simulation manifest's
  render.py digest is stale; this auxiliary mismatch remains visible.
- Corrected common-launch glide results retain one unconverged row, no robust
  candidate winner and scenario-dependent rankings. Nominal successes do not
  erase these counterexamples.
- Target-fish held-out biological accuracy and calibration remain unknown.

Project recommendations use explicit essential-blocker/dependency categories.
Expected information gain, utility and global biological probability remain null
until defensible outcome/cost/calibration models exist. Candidate-specific
prospective ensembles are imported when their fixed paths exist, with exact
protocol/run/predicate pins. The importer checks committed protocol byte identity
and ancestry before the declared run-code revision, recomputes both load cases
per trial from saved metrics, and rejects altered counts, empty denominators,
wrong input/output hashes or changed predicates. It does not independently witness
the author's wall-time execution ordering. Conditional simulated pass fractions
stay separate from biology. `regions.svg` is a categorical UI schematic rendered
from the vector, with a separate renderAction; it is not a specimen or state field.
