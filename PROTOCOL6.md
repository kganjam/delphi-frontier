NCA (the owner of the question and the outcome definitions) is informed by file; I use NCA's code at a pinned commit and change no definition. Evidence kind `simulated` (declared model) plus `formal` (exact linear verdicts). **Not a claim about any tissue or fin.**

## Purpose
The frozen NCA sweep (2,520 cells, 10 parameter draws per model, CPU, about 2.8 h) gives the quantities R1 to R3 for ONE ensemble draw. The atlas asks whether they generalize: the same design (same prior, same factors, same outcome definitions and analysis code) on **40 new parameter sets** (20 per model, ensemble master seed 20261101, no parameter set shared with the frozen draws: overlap 0, checked) and a **new initial-state seed 518331**, 2,520 cells in total, computed on one H100 in minutes instead of about 3 CPU-hours. It also serves as the substantive held-out/control check of the GPU solver at scale. It is a held-out replication of a design, **not** a new preregistered finding about biology; NCA's predictions P1 to P5 are re-evaluated on it and reported, not gated.

## Cells (`inputs/atlas_cells.json`, sha256 `270d3a8cb850bf093ed07fa1fdb66ebbaa9bf3077c1efdc3a5218fec576049e8`)
`frontier_compute/atlas.py` (sha256 `37416bdecc0e8931e02ff3c379324cc9a3fea2bb628dd87d7f3b2b874f6b2480`): `ensemble.build(20, seed=20261101)`, seed-101 copies re-seeded to 518331, ids offset 200000; 1,440 linearly unstable (`applies`) and 1,080 linearly stable (`out_of_scope`). Refinement subset (dt-half, grid-double, perturbation arms): draws 0 to 4 of each model, 630 cells. Control cells: 48 = 2 models x rho in {0.7, 0.97, 1.5, 3.0} x eps in {0.01, 0.3} x 3 cells sampled with `random.Random(20261102)` from the refinement subset.

## Execution (every step bounded)
1. **GPU (one H100, 30 min server timeout, inner budget 540 s, one job)** `frontier_compute/atlas_entry.py` (sha256 `bff01adffde081c5039294b335c881b806173ed5d0ee52fdfca5da99acfe658d`): solver A (float64, vendored NCA scheme, `gpu_neumann.py` sha256 `64ce2d6acf1010bda1c17454f760d31530e18364b931247e8a9e9c4919c758a5`) on all cells (arm `base`), then arms `dt2` (dt 0.01), `grid2` (2N cells), `perturb` (1e-10 relative initial noise) on the refinement subset, in that priority order; cells batched by (model, grid size <= 100 or > 100). Only metrics are returned, plus `u_final` for the 48 control cells in `base` and `dt2`. An arm or batch not run within the budget is recorded, and a cut base arm makes the atlas INCONCLUSIVE. Telemetry sampler on (assigned-device vs per-process, raw CSV hashed).
2. **Local CPU (2 processes, 1 thread each, `cpu_atlas.py` sha256 `32584922a31c5feb344689f86e8407129d69abd1f2f8efd5637a4bd59592531e`):** independent solver B (scipy BDF, NCA's `run_cell_b`) on ALL cells, and solver A (numpy, dt 0.02) with fields on the 48 control cells.
3. **Analysis** `atlas_report.py` (sha256 `0292f23f620cf452b773f88f2e33b1190cd0aeff6071bc78becd78f0b128f845`): NCA cell categories computed exactly as in NCA's `run.py` (A = GPU base arm, B = CPU BDF; `TOL_AMP_SOLVERS` 0.15; unresolved mass stays in every denominator), then NCA's own `analyze.py` (vendored at their commit `4542265`, sha256 `69ec3bc8e99466d0ea1f50215256a5c7151e7f60b65d9e6665bfd533b670697e`, unchanged since `cb27cf2` for the solver files) for R1 to R3 by stratum and P1 to P5.

## Validation gates (decide the label of the atlas, fixed now)
* **V1** on the 48 control cells that are step-converged (`e_dt` <= 0.01, with `e_dt = max|u_dt - u_dt/2| / |u*|` from the GPU base and dt2 arms; the CPU A reference is a single dt, so step convergence is judged on the GPU pair): the revised agreement criterion of Protocol 2 (pattern flag, settled, diverged equal; dominant mode equal where the CPU cell is patterned; whole-field error <= max(1e-9, 2 e_dt)) holds for every such cell.
* **V2** homogeneous control: every cell with rho = 0.7 and eps = 0.01 (all 2,520-cell grid) is non-patterned in both A (GPU) and B (CPU).
* **V3** checker mutations on V1 cells (mode +1 on patterned, flag flip, error of 10 x tolerance, settled flip) each rejected on 100% of applications.
* **INCONCLUSIVE** if the base arm is incomplete, or more than 25% of the 48 control cells are not step-converged, or fewer than 8 patterned step-converged control cells.
* Label: **VALIDATED** if V1, V2, V3 hold and not inconclusive; **NOT_VALIDATED** if a gate fails; INCONCLUSIVE as above. The atlas tables are computed and published under whichever label, with the label on every table and caption. No gate or threshold is changed after results.
Reported, not gating: P1 to P5 on the held-out draws; unresolved mass and reasons; the old mode-on-every-cell rule's failures on the control cells; the sensitivity report (how many cells change NCA category if solver A is replaced by its dt2, grid2 or perturbed version, flag flips, mode flips on the 630-cell subset); GPU telemetry; runtime.
